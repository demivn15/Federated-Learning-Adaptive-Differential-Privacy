# Origin and project modifications

This repository contains a modified copy of NEBULA, developed by CyberDataLab and the upstream contributors. The base source is commit `525b31c674644c653117126b5a1473a5321ac240` from https://github.com/CyberDataLab/nebula.

The original GNU Affero General Public License, version 3, is retained in `LICENSE`. Upstream copyright statements and bundled asset notices remain in the source. The original repository documents and workflow definitions are retained under `docs/upstream/` for reference.

Mateo Oñate and Demian Viteri prepared the research application for federated breast tumor classification, with CPU deployment, a controlled WDBC split, cumulative Opacus accounting, public-reference adaptive clipping, result presentation and experiment checks. This package includes the supporting installation tools and measured evidence from the project.

The repository is a research extension of NEBULA. It does not represent the framework as an original implementation by the project authors. The WDBC dataset has its own attribution and license, documented by UCI. Other bundled components retain their original notices.
