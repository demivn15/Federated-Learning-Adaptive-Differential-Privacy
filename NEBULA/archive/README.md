# Historical project material

`development/` preserves the original workspace scripts, READMEs and validation snapshots before repository organization. Those files contain historical machine-specific paths and assumptions. They are records of earlier work, not the active installation entry points.

`proposal/` preserves the original research proposal, its LaTeX sources and template assets. That proposal predates the final WDBC/NEBULA application and is not the current protocol description.

The active commands are under `scripts/`. Current scientific assumptions and limitations are documented in the root README and `docs/project/`.
